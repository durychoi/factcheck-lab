# 팩트체크 분석 화면

기사 속 주장 한 문장을 입력하면 Tavily로 근거를 모으고, 그 근거만으로 Gemini가 6단계 판정을 내립니다.

## 여는 방법
`index.html`을 더블클릭해 브라우저로 엽니다.

## 사용
1. 상단에 Tavily 키와 Gemini 키를 입력합니다(이 브라우저의 localStorage에만 저장).
2. 주장을 입력하고 [분석]을 누릅니다.

## GitHub Pages
저장소에 이 폴더를 올리고 Settings → Pages에서 브랜치를 지정하면 됩니다. 키는 코드에 없으므로 함께 올라가지 않습니다.

## 설계 원칙
- 판정은 Tavily 근거 목록만으로 수행(temperature 0).
- 출처 URL은 Gemini 응답이 아니라 Tavily 근거 목록에서 번호로 찾아 붙임. 목록에 없는 번호는 버림.
- 근거 0건 또는 유효 근거 번호가 없으면 "판단 유보".
- 검색은 `advanced`. 우선 출처(정부·법원·통계청·학술·언론)로 1차 검색하고, 5건 미만이면 전체 검색으로 채움.
- 출처 유형([공공기관] [학술] [언론] [백과] [기타])은 `sources.js`의 도메인 표로 코드가 분류. 매체를 추가하려면 이 파일만 수정.
- 판정에 쓴 근거가 모두 [기타]이면 "판단 유보" 외 판정을 내지 않음(Gemini 지시 + 코드 강제).
- 미래 예측·전망, 가정, 의견은 근거가 있어도 "판단 유보"(주장 유형을 먼저 분류, 코드 강제).
- "거짓" 계열은 반박하는 사실 근거, "사실" 계열은 지지하는 사실 근거가 있어야 함. 지지 근거가 없다는 것만으로는 거짓이 아님.
- 화면의 근거 번호는 Gemini에 전달한 번호와 같음. 이유 문장에서 인용한 근거는 모두 "판정에 사용"으로 표시. 목록에 없는 번호는 [번호 오류].
- 판정 보정 로직은 `judge.js`, 근거 선정은 `evidence.js`.
- JS·CSS 수정 후에는 `index.html`의 `?v=` 값을 바꿔야 브라우저가 새 파일을 불러옴.
